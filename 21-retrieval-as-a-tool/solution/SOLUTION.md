# Solution for Lesson 21: Retrieval as a tool

The simple gate handles pure smalltalk and fails exactly where you would predict: a handoff request ("can I talk to a person please") carries content tokens and searches pointlessly (harmless but wasteful), and the courier question searches and retrieves delivery chunks that look relevant, the dangerous failure, because the agent now has context inviting it to answer a question the corpus does not govern. A bigger smalltalk list fixes neither; a token rule cannot see intent. Both are model shaped judgements (is this message asking about the world the corpus covers?) with rule shaped backstops. The production shape this argues for: rules for the certain cases (exact smalltalk, empty content), a model gate for the rest, and Lesson 20's refusal as the safety net for everything the gate gets wrong, because gates are probabilistic and refusal is the layer that must not be.

# Visual guide

Every core idea in this course has a diagram. They are drawn in one
style so the shapes stay familiar: navy boxes are the main actor or
step, light boxes are supporting steps, amber boxes are gates where
a human or a safety check decides. Each diagram also lives inside
the lesson it belongs to.

| Diagram | What it teaches | Used in |
|---|---|---|
| [course-map.svg](course-map.svg) | The whole course on one page: 10 modules, one corpus, one system | README |
| [rag-pipeline.svg](rag-pipeline.svg) | Documents, chunk and index, retrieve, answer with citations | Lessons 01, 18 |
| [chunking.svg](chunking.svg) | Whole documents, paragraph packing, sections, parent expansion | Lessons 03, 04 |
| [hybrid-fusion.svg](hybrid-fusion.svg) | BM25 and vector legs fused by reciprocal rank fusion | Lesson 11 |
| [evaluation-loop.svg](evaluation-loop.svg) | Golden set, run, score, decide: change one thing at a time | Lessons 18 to 20 |
| [agent-loop.svg](agent-loop.svg) | Decide, search, grade, answer or refuse, retry once | Lessons 21 to 24 |
| [capstone-flow.svg](capstone-flow.svg) | Spec and gates, build, evaluate, ship | Lessons 28 to 31 |

Diagrams are generated by [generate_visuals.py](generate_visuals.py)
so the set stays consistent. Edit the script, rerun it, and commit
the SVGs it writes. Every use carries descriptive alt text, so
screen-reader learners and search engines get the same content as
sighted readers.

# Solution for Lesson 15: Query rewriting and vocabulary bridging

A correct run grows the table by at most three rows (one per genuine gap; a question needing two rows usually signals a decomposition problem, Lesson 16, not a vocabulary one), lifts each target question to fact recall 1.0, and leaves the golden set at 0.9615. The sabotage row's effect is the governance argument made measurable: a wrong bridge injects the wrong document's vocabulary into unrelated questions, and at least one golden question's ranking degrades, typically a gift card or loyalty question whose top chunk gets competition from the bridged term. The production rule follows: a row enters the table only with (1) a real failed question attached, (2) both sets rerun and recorded, and (3) a reviewer's sign off, because the table is code that edits every future query, and it should be reviewed like code.

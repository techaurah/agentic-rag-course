# Solution for Lesson 04: Structure aware chunking

On the reference build, whole document expansion lifts fact recall at 5 from 0.9615 to 1.0 (the union of the top 5 documents contains every gold fact for every answerable question) at an average of about 359 context words, triple the child's 118. So the spectrum reads: the recall gain on this corpus lives entirely at the document level, and it costs three times the context for the last 0.0385 of recall. For legal contracts with multi page sections, the rule inverts: section expansion there is the cheap middle (sections carry complete clauses), document expansion is unaffordable, and the measurement to run is fact recall and condition recall at each level on a contract golden set, choosing the cheapest level whose condition recall stops improving. The transferable skill is building the spectrum and pricing each step, never adopting an expansion level because a framework defaults to it.

# Solution for Lesson 11: Hybrid search and fusion

With the vector leg shuffled, the hybrid's fact recall at 5 slips only slightly on the reference build (BM25's ranking dominates the fused order for most questions) but its worst case and MRR degrade visibly, and the questions where the vector leg was the rescuer (its unique saves) fall back to BM25's answers. The property demonstrated is graceful degradation: RRF has no weights to go stale and no score scale to explode, so a dead leg costs quality, not correctness of the mechanism. Production monitoring follows directly: log per leg agreement (how often each leg's top chunk survives fusion) and per leg golden set scores on a schedule; a leg whose agreement collapses or whose standalone recall craters is the silent failure this exercise simulates, and it is invisible if you only watch the fused metric.

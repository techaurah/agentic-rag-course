# Solution for Lesson 27: The failure playbook

On the reference build the split is mostly (a): q10's guarantee period and sale treatment, q29's hours and cafe locations, and q11's dates live across chunks, so no sentence selection improvement can fix them; a generating (or multi-sentence) composer is the only road. The (b) cases, where a complete sentence existed but lost the ranking, respond to better selection (the composer's shared token scoring is crude beside a model's judgement). A team reading a mostly (a) table should stop tuning selection and change the composer's shape; a mostly (b) table says the opposite. The exercise's real deliverable is the ratio itself: it converts "our answers feel incomplete" into an architecture decision with evidence attached, which is the playbook's entire purpose.

# Solution for Lesson 16: Query decomposition

A semicolon plus condition rule lifts the reference splitter part way: q09 splits into its condition and its question, and its union recall recovers, while q28 (a single clause question about a rule interaction) still does not split, because nothing in its surface marks two facts. Expect auto union recall to land between 0.8 and 1.0 and treat any claim of exactly 1.0 from surface rules with suspicion: the last cases are semantic, which is the measured argument for a model based decomposer. The CI acceptance test for a nondeterministic decomposer: run it over the multi-hop golden subset plus a sample of single fact questions, assert mean union document recall at or above the single shot baseline (0.9 here) with no single fact question's recall degraded, and assert the subquery count stays within a budget (say, at most 4 per question); run it on model or prompt changes, not on every commit, and record the outputs so regressions are diffable. Nondeterminism changes how you test, not whether you test.

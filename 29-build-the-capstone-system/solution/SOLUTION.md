# Solution for Lesson 29: Build the capstone system

No code changes: the loader reads the manifest, the chunker cuts the new document, both indexes absorb it, the filters honour its roles, and the composer can cite it, because every stage is corpus driven. Your answerable question should be answered with a citation to the new document, and the omitted detail question should refuse via the unseen concepts rule if its key terms are genuinely absent. The architectural conclusion: knowledge lives in the corpus and its metadata; the code is a set of corpus agnostic mechanisms, which is why extending the system is an editorial act (write a document, annotate questions) rather than an engineering one, and why corpus governance (Lessons 02 and 19) is the operational discipline that decides whether a deployed RAG system stays true as it grows.

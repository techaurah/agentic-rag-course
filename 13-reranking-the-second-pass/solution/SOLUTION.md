# Solution for Lesson 13: Reranking

The settling experiment: run both configurations over the golden set AND the gap set AND a held out set of real user questions sampled from logs (the set neither side tuned on), reporting fact recall at 5, precision at 3, and answer level scores from Lesson 20's grounding checks. Keep the reranker if the held out set and answer level metrics improve, even against a flat golden result, because the golden set may be saturated; remove it if gains appear only on the golden set (the tuning target) or only anecdotally. On the reference build the gap set portion ties: both configurations score the same fact recall at 5 on the gap questions, because the gap failures are coverage failures (the gold chunk is absent from the candidates), and reordering an absent fact changes nothing, Lesson 11's limit restated in reranking clothes.

# Changelog

All notable changes to this course are recorded here. The format
follows Keep a Changelog, and the course versions follow semantic
versioning for the course as a whole.

## [1.0.0] - 2026-11-06

### Added

- Complete course: 32 lessons (00 to 31) across 10 modules, from
  the five measured failure modes of a naive RAG pipeline to a
  complete evaluated RAG system that passes acceptance gates
  fixed in advance.
- The Fernhill corpus: 24 fictional documents for a garden
  centre chain, with roles, dates, and a superseded sale
  document, plus a 32 question golden set (26 answerable, 6
  refuse-expected) and a 6 question vocabulary gap set. Every
  number in every lesson is the output of that lesson's own
  code on this corpus.
- The full retrieval stack on the Python standard library:
  paragraph and section chunkers, TF-IDF, BM25, a deterministic
  hashing embedder (a labelled teaching stand-in), reciprocal
  rank fusion, role filtering, freshness handling, synonym
  rewriting, decomposition, an extractive grounded answerer
  with citations and refusal rules, and a deterministic
  evaluation harness.
- Honest negative results, kept in the course on purpose:
  deterministic rerankers did not beat rank fusion on this
  corpus, a template HyDE stand-in added no vocabulary and no
  gain, and pseudo relevance feedback drifted the gap set
  backwards. Each is measured, not asserted.
- Tools for contributors: a course validator (JSON examples,
  golden set schema, capstone config sections) and a relative
  link checker, both wired into CI with per lesson smoke tests.
- Visual set in the TechAurah Academy style: course map, RAG
  pipeline, chunking, hybrid fusion, evaluation loop, agentic
  loop, and capstone flow diagrams, generated by a committed
  script.

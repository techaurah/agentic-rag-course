# Exercise for Lesson 28: Capstone spec

Argue with the spec, on paper, before building: pick the gate you consider most at risk on a corpus ten times this size with real user questions (not author written ones), and write the case: which reference value degrades first, by what mechanism, and what you would change in the system (not the gate) to defend it. Then pick the gate you would tighten for a customer facing deployment and justify the new threshold with the trade it accepts, using Lesson 20's dial numbers where relevant.
